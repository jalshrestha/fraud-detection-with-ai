\subsection{Dataset Characteristics}

The full pipeline produces a graph of \num{85680} unique Ethereum
addresses connected by \num{239742} transactions.  Of these, \num{304}
addresses carry both verified Solidity source code and an explicit
fraud/benign label (Table~\ref{tab:dataset}).  Within this eligible
subset, 95 contracts are labelled fraud (31.3\%) and 209 are benign.
The stratified 70/15/15 split yields 212 training, 45 validation, and
47 test contracts, with class weights $w_0 = 1.0$ (benign) and
$w_1 \approx 2.37$ (fraud) computed from the training split to prevent
leakage into validation and test evaluation.

\subsection{Code Structure and Reproducibility}

The codebase under \texttt{code/} is organised into nine library modules
and one scripts directory:

\begin{enumerate}
    \item \texttt{config.py}: single source of truth for all paths,
    hyperparameters, model names, and API keys.
    \item \texttt{data/addresses/}: the two explicit seed arrays,
    \texttt{FRAUD\_ADDRESSES} (156 DeFiHackLabs victim contracts) and
    \texttt{BENIGN\_ADDRESSES} (504 blue-chip protocol contracts).
    \item \texttt{src/collection/}: Etherscan v2 source-code fetcher,
    Forta label loader, BigQuery transaction exporter.
    \item \texttt{src/preprocessing/}: address lowercaser, DuckDB
    integration engine, PyG graph constructor with eight-dimensional
    node feature computation.
    \item \texttt{src/datasets/}: \texttt{ContractDataset}, which
    pairs Base64-decoded Solidity tokens with graph node indices for
    the DataLoader.
    \item \texttt{src/models/}: \texttt{GraphEncoder} (two-layer
    GraphSAGE), \texttt{load\_codebert} (frozen CodeBERT loader), and
    \texttt{FusionClassifier} (the full fusion head).
    \item \texttt{src/training/}: AdamW optimiser with cosine-annealing
    LR schedule, early stopping on validation fraud F1, gradient
    clipping, and best-checkpoint persistence.
    \item \texttt{src/evaluation/}: \texttt{evaluate\_model} returning
    precision, recall, F1, AUC-ROC, AUC-PR, and MCC; all six ablation
    classifiers; Random Forest baseline.
    \item \texttt{src/visualization/}: figure generators for the
    confusion matrix, loss curve, and ablation bar chart.
\end{enumerate}

A \texttt{scripts/} directory contains seven numbered executable
scripts (01--07), one per pipeline step, each reading from and writing
to deterministic paths under \texttt{data/processed/} so that any step
can be re-run independently after its prerequisites exist.
The random seed 42 is applied at both the Python and PyTorch levels
before any stochastic operation, ensuring full reproducibility on the
same hardware and library versions.
